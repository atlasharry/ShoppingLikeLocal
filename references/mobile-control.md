# 手机访问与结果回读

网页缺少评论、账号优惠或配送信息，或用户指定购物App时使用。优先复用已授权连接和账号，切换设备后继续原任务。连接状态随会话变化，本文件不替任何设备预先声明可用或不可用。

## 选择后端

先读当前工具文档，再确认用户指定设备。专用手机工具与可交互镜像都可使用；普通投屏、用户截图、ADB在线或工具已注册，只证明对应环节。多设备时不按第一台猜选。

| 路径 | 必要前提 | 验证边界 |
|---|---|---|
| iPhone Mirroring＋原生电脑控制 | 兼容Mac、macOS15+、iOS18+；同Apple账户和双重认证、附近且锁定的iPhone、蓝牙/Wi-Fi开启；地区及管理策略允许 | 分别验证截图、点击、滚动与输入；相机、麦克风、Face ID不能通过镜像代办，解锁手机会中断镜像 |
| Android现有控制接口或ADB＋scrcpy | 对应电脑工具、手机调试及本机RSA授权已就绪；无线另需配对条件 | 在线不等于可视控制；scrcpy无需root，支持macOS/Windows/Linux，仍须验证画面与输入 |
| Mobile MCP等适配器 | 当前版本运行时、平台依赖及设备端授权齐备 | 当前Mobile MCP使用mobilecli后端，iOS真机仍需设备端agent及签名；不能照抄旧WDA教程或将xcrun存在当成就绪 |

购物授权不自动包含安装工具、开启调试、配对或改变安全设置。已有明确配置授权时按范围执行；否则列出具体缺口，准备对应接入方案。不要绕公司管理策略，也不为普通购物默认启用云手机或远程设备。

手机镜像连接与电脑控制工具的屏幕录制/辅助功能权限分层核验，不能用其中一个成功推断另一层。若已获准配置scrcpy，按当前文档区分SDK与UHID键盘、设备输入法及剪贴板同步；不把ASCII输入成功当中文成功。默认同步可能带入无关剪贴板，按工具许可选择相应隔离配置；此技能不会自行开启调试或修改系统设置。

## 记录 `access_state`

用普通表格记录设备别名、后端、App、登录状态、最后读取时间、各动作结果及缺口，不必创建全量schema。

| 状态 | 可观察依据 | 后续动作 |
|---|---|---|
| `verified` | 指定设备当前画面可读，可逆操作及回读成功 | 只使用已验证动作，中文输入、登录及购物阶段仍单列 |
| `view_only` | 只有画面或用户截图，输入不可用或未授权 | 用户操作、代理读图；说明截图时间，不称自主控制 |
| `needs_user_setup` | 等待解锁、认证、连接、验证码或App登录 | 保留上下文，继续不依赖手机的工作 |
| `unavailable` | 无可用后端，或当前失败无法继续 | 回网页或用户资料，缺失证据留空 |
| `not_tested` | 本次尚未检查该动作或平台 | 不提前声明成功或失败 |

先读画面，再做不涉及购买、发布或设置变更的可逆操作，最后重新读取。能回主页、输ASCII或启动App，不推出中文输入、App内搜索、评论、优惠和结算都已验证。覆盖按[平台阶段](platforms.md)分别记录。

## 中文输入与剪贴板

输入方法返回成功不等于文本正确。提交搜索前必须回读目标字段；空值、乱码、截断和旧剪贴板内容都视为失败，不带错误文本继续。

直接输入失败时，可用当前已验证输入法或由用户输入。需要系统复制粘贴时，仅在已确认不会自动保存、发送或提交业务内容的临时输入控件暂放**本任务查询**，例如未提交的浏览器地址栏。不要借用聊天框、共享文档或笔记正文；取消编辑不能撤回自动保存。无法确认时，改用已验证的文档化剪贴板接口或交给用户输入。

1. 读回该字段，确认只有预期查询。
2. 系统全选、复制；取消该字段编辑或导航，避免意外发送。
3. 聚焦手机目标字段、系统粘贴；重新截图/读取，确认完整文本后才提交。

一次实测已通过“原生Chrome地址栏放入查询并读回 → 系统复制 → Escape取消导航 → iPhone镜像目标搜索框粘贴 → 截图确认”。这是可选回退，不是任意App通用保证，不固定Chrome元素索引或坐标。浏览器会话的 `clipboard.writeText` 不一定更新手机可读的系统剪贴板；会自动恢复旧剪贴板的辅助粘贴方法，也只能按目标字段实际结果判定。

只复制本任务内容，不读取、保存、转述或发布用户原有私人剪贴板。手机壳层输入成功后，购物App内搜索框仍需重新验证。

## 补证与交接

- 原帖、图片、评论和未展开回复按[来源与视频](sources-and-video.md)记录；推荐流不替代原帖。
- 先核 `product_identity` 再匹配 `offer`；电脑与手机型号、地区、容量、套装或卖家不同，不合并价格。App券与网页券不自行叠加。
- 交接保留用户条件、查询词、候选、产品/报价身份、来源标识、读取范围、时间、配送地区、已授权及未完成动作。无可复制链接时保留商品标识及必要截图，不编URL。
- 验证码、扫码确认或生物认证交给用户；普通登录按已有授权与工具规则处理，不借另一账号补缺口。

设备授权与加购、订单、支付、会员和对外互动分开。沿用已明确的商品、数量、金额和配送范围，不增加每次统一确认；实质变化或关键授权缺失时，先准备可审查结果，再补对应信息。购买核验见[价格与履约](price-delivery-purchase.md)。

## 故障与恢复

画面冻结、捕捉失败、锁定、断连或验证弹窗出现后，停止依赖旧画面的输入。普通故障按已知原因有限重试；仍失败就更新状态，回网页、用户操作或截图分析。若属于工具、站点或权限安全拒绝，按[平台路线](platforms.md)停止该动作及等效绕行；解锁、登录或换设备不自动解除拒绝。不靠改安全设置、换账号或规避验证继续。

恢复后重核设备、App、商品、规格及数量。加购/提交结果不明时先读车或订单，不重复点击。最终分别报告连接、资料读取、加购、订单与支付阶段。截图仅留必要区域，公开前移除账号、地址、手机号、订单号、支付信息、二维码及会话令牌。
