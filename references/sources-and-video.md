# 来源、主张与视频

按用户地区、语言及指定渠道找体验；中国平台与其他地区论坛、评测或零售评论可并用。先核产品身份，再判断来源能支持哪项 `claim`。平台数量和赞数不替代证据质量。

## 原帖与评论

从用途、场景、同义词和准确型号查询，再补复购、长期、对比及本品相关失败条件。已有候选就追查会改变选择的疑点，不机械铺查询网格。

打开正文、实物配图和相关回复。搜索摘要、AI汇总、推荐比例只作定位；“避雷”“祛魅”等否定标题也可能反转荐购，不能看标题就归为负面。

采用一条主张时，保留这些原始事实，表格或短笔记即可：

| 对象 | 记录内容 |
|---|---|
| `product_identity` | 实物/包装、完整型号或P/N、地区、代际、容量及配方是否匹配 |
| 使用条件 | 对象、环境、用量、时间、工具、操作及追踪时长 |
| `claim` | 谁说什么；作者口述、画面展示、观众复验分别是什么 |
| 读取范围 | 发布及观察时间、读到的主评论、已展开回复和缺失部分 |

共90条而只见两条就记两条；THE END也不证明所有子回复已展开。区分实际使用、刚下单、提问、作者答复、未说明条件的赞否、不同款和重复话术。包装、气味、性能及材质误用分别处理，负面同样核版本与操作。

即使读完全部评论，自选和排序样本也不是销量或实际使用人数的故障率分母；评论猜测不等于维修诊断或因果复验。

字面赞否先结合正文、父评论、讽刺对象和后续更正判断；反话指向不明就保留歧义，不强行计正负比例。采集器声称支持回复，也须核当次是否启用、加载上限、截断及返回字段，不能继承“全量”宣传。

## 访问不足时换可读通道

DOM、原生AX、截图或App各自记真实范围。DOM未返回B站评论，不证明无评论或已删除：检查当前页面，再用已授权原生电脑控制滚到评论区，通过AX或截图读取。仍缺失时可切已验证手机，或保留缺口。上述互补只适用于普通读取不足，不能绕过[平台路线](platforms.md)所述安全拒绝。一个通道的空结果不等于整个来源为空，不提取Cookie、猜接口或借账号补全。

## 推广风险、证据质量、独立性分开

- 合作声明、佣金商品卡、购买链接、优惠口令、集中推品、复用素材和模板评论是推广信号。未见信号不证明无商业关系；有导购也不自动否定可核数据。
- 条件清楚的过程、可重复对比、失败记录和后续追踪决定证据能支持什么。无推广的个人帖也可能认错款或操作错误。
- 同作者跨平台、关联账号、同一前后图或品牌供稿归为来源组。不同作者共用同一报告，该报告仍只有一份实验；作者各自新增的观察另记，转载不增加实验次数。
- 评论荐博主、UP贴文章、文章引用厂家报告，是引用链，不是三份独立实测。记录报告编号、实验者和原始出处；没读报告图就不称已核报告。

厂商说明也绑定准确型号、地区和修订版本；同品牌/系列不足以转移规格、禁用条件或时长。官方效果宣称与完整报告分开；报告还看型号、滤芯/配方、条件、终点、日期和测试对象。

用户指定平台权重时，用于体验取舍，不把安全、禁用材质、电气兼容或使用规范变成社区投票，也不伪造精确可信度或推荐比例。

## 视频内容

| 可读内容 | 用途 | 边界 |
|---|---|---|
| 创作者字幕、带时码文稿 | 定位型号、数字和实验 | 关键数字与否定词回听 |
| AI字幕、AI总结、观众笔记 | 找相关片段 | 不当独立实测或逐字事实 |
| 章节 | 跳转操作或结论 | 看对应片段及前后画面 |
| 视频画面 | 核实物、操作和结果 | 核对象、光线、用量、力度、时长、剪辑 |
| 评论及回复 | 长期复验、失败和条件 | 真用过、同版本、是否独立于原片 |

先查当前视频实际有哪些入口，不假设每片均有字幕、文稿或AI总结。不发评论召唤机器人；那是对外互动，需对应授权。

记录视频标识、起止时间和所见。抽看就写抽看，连续看过才写连续观看；完整字幕不等于完整观看。只见泡沫和擦洗不推出水垢已净。性能数据对齐单位、分辨率、模式、超分/帧生成、供电和测量条件；口播“翻倍”不证明同条件结果。

无字幕且口播影响决策时，可处理平台允许下载、作者提供或用户合法持有的本地素材，以已具备ASR生成原语言带时码SRT/JSON。没有素材就报告观看范围，不绕登录或调用非公开接口。安装或外发另按现有授权。转写可能错认品牌、剂量、数字、否定词，甚至幻觉或重复；关键主张回听回看。ASR支持口述内容，不证明实验已发生或有效。
