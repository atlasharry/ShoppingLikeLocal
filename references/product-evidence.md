# 产品身份与关键证据

用于型号、参数、适用性和技术主张决定购买的任务。只核影响当前选择的信息，不要求每件日用品填完整参数表。

## 两种身份

**产品身份**：品牌、完整型号/P-N、代际、地区、电源/配方、固有配置、尺寸、单包装净含量及包装内件数。厂家独立SKU的标准套装保留其内容；卖家临时加赠或组合另放报价。地区或配置未知时标为未确认，不按标题强并。

**报价身份**：对应产品、平台及商品ID、卖家、履约方、所选规格、本次购买数量、成色/翻新状态、卖家套装及加赠配件、保修、优惠资格、价格阶段、配送地区和核验时间。包装内两只与购买两包分开。不同卖家可卖同款；同一商品链接也可能合并多个型号及评价。匹配同型号后仍要比较购物篮和成色，不能把旧机最低价当新机报价。

制造商家族页、客服和商品参数栏也会有模板错误。出现冲突时回到对应SKU的铭牌、说明书或具体规格图；不能仅因来源写着官方，就把全页数据绑定到每个版本。

## 一条决定购买的数字

记录数值及单位，并补充实际可取得的：测量对象、标称或实测、地区/配置、测试所用耗材或附件组合、档位/模式、测试条件、标准版本、报告身份，以及读到了原始报告还是只见引用。主机适配某滤芯，不把另一组合的测试值自动带过来。

- 说明书额定值、厂家样机实测和独立实测分开列。统一口径后才比较大小或倍数。
- 下限、区间和等级保持原意；不能把门槛当精确极限值。
- 部件可安装、接口形状相同、支持输入信号，不证明目标任务的整机性能。
- 同一报告被官网、社区和视频引用仍是一份实验。来源数量与独立实验数量分开。
- 没找到资料表示未核实，不自动等于不支持。缺少关键条件时缩小该项结论，不给整机编造性能。

## 品类中的高价值检查

| 类别 | 需要分清的条件 |
|---|---|
| 投影仪 | 光源亮度、整机光通量、中心照度；ANSI/CVIA/ISO口径；原生面板、像素位移与4K输入；刷新率对应分辨率；原生/动态对比度；投射比与幕宽；镜头位移与机身倾斜；画面模式对应的噪声 |
| 游戏本 | 完整CPU/GPU后缀、显存、功耗模式、内存焊接/插槽、屏幕、地区；机身+适配器+线材携带重量；原始帧与帧生成；分辨率/画质/超分/插电状态；续航测试负载 |
| 空气净化器 | 颗粒物与气体、CADR速度与CCM容量、额定与睡眠档、单成分与混合气体；准确主机+滤芯组合；吸附/化学吸附/催化、维护与再生恢复量/副产物；测试容量与日历寿命；气味或家用传感器不作污染物确证或入住证明 |
| 扩展坞 | 上行/下行、视频/数据/供电角色、协议而非插头形状；主机/OS→输出/转换→线材→显示器输入的分辨率×Hz，必要时核DSC/色深/HDR；允许直连时保留显示器直连、hub管外设方案 |
| 清洁/洗护 | 准确配方和禁用材质、浓度/用量/等待/冲洗；普通污渍、染料转移、自身掉色与主动脱色；底布、印花、拼色及涂层分别核适用性；“护色”不保证每种印花安全 |
| 床品 | 纱支/TC/股数/织法分开；FP、充填重量、整重与热阻分开；夜间室温和触感偏好；床垫/床笠、被套/被芯、枕套/枕芯各自尺寸，承托与抱持用途不同 |
| 热造型工具 | 加热板、板背/外壳、隔热端、握柄、护指和收纳罩逐部位核；板温控制或cool tip不证明整个外壳冷触；型号、代际、运行档位与时长对应 |
| 固定与水路配件 | 胶条/吸盘等固定方式、基材表层、载荷/厚度/背孔及拆除空间；水路螺纹公母/直径/螺距、隐藏式结构及密封；调角、有效行程和软管长度不互代 |
| 食品与耗材 | 净含量/件数、批次、日期、原装或替代、完整更换套装；低单位价是否需要超量购买 |
| 二手与翻新 | 整机状态和耗材状态分开；计数复位不证明全新；凭证、维修记录、明确缺陷和退换责任 |

投影距离可用“画面宽度×光学投射比”核算；斜投、梯形处理、镜头高度等安装条件仍需另核。没有可比测试时，不凭一种亮度数字或GPU名称给出绝对性能排名。

## 使用成本与建议

先给购入总额，再给额外1/2/4次完整更换耗材的情景支出。包含的第一套不能重复收费。只有提供可信负载与寿命条件时才估日历周期；明确是情景而非用户家的寿命保证。返现、积分、旧机残值和赠品不直接当作现金减价。

先排除不满足硬约束的款，再比较影响使用的优势、缺点和价格。关键安全或禁用条件明确失败就排除，未核实则不授予首选；不以预算或其他优点抵消。其他不影响硬约束的未知可给条件性首选，并说明条件。实屋效果、长期可靠性或安全结果不能仅由型号规格保证；健康用途分清源头控制、适宜通风和净化辅助作用。保留便宜、较旧但适合需求的选项；不把新款或更高售价自动当成更好。
