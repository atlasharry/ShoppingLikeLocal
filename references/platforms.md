# 平台覆盖与访问路线

ShoppingLikeLocal用于不同国家和地区。以所在地、购买地、语言、渠道偏好和授权为准：中国平台不是全球任务必选项，国际平台也不默认直邮用户所在地。

## 分阶段验证

一个入口能搜，不等于能读评论、选款、确认优惠或购物。记录 `access_state`、平台/市场、网页或App入口、登录身份范围、时间和已读内容；只列本次需要平台。

| 阶段 | 通过依据 | 不能直接继承的结论 |
|---|---|---|
| 发现 | 当前搜索/聚合出现可识别候选 | 商品卡或标题不等于原帖、评论或在售确认 |
| 原帖/评论 | 正文、配图、相关主评论及回复可读，范围已记 | 评论总数不等于已读数，转载不增加独立实验 |
| 选SKU | 当前选中完整版本、配置、容量或套装 | 系列起价、默认规格不等于目标款 |
| 商品价 | 当前所选款、数量和币种有报价 | 页面/接口/聚合价不等于账号确认价 |
| 确认价 | 当前账号、优惠、数量、地址和税运服务费核齐 | 宣传券、他人截图、其他地区价不自动适用 |
| 配送 | 同地区库存、发货、到货及必要送装可见 | 发货速度不等于送达或安装承诺 |
| 执行 | 授权动作后有准确车行、订单或支付结果回读 | 登录、连接、点按钮或确认页不证明购买 |

需要汇总时，一行一入口：

| 平台/市场与入口 | 发现 | 原帖/评论 | 选SKU | 商品价 | 确认价 | 配送 | 执行 | 时间/缺口 |
|---|---|---|---|---|---|---|---|---|

每格填“已核＋证据位置”“部分＋读取范围”“未核”“受阻＋原因”或“不适用”。不预填平台全通，不为填表进行无关调研；简单追问可以直接用已有资料回答。

## 平台角色与区别

| 平台/来源 | 常见用途 | 重点核验 |
|---|---|---|
| 小红书 | 场景、长期体验、评论追问 | 原帖实物版本、反转荐购、回复范围、导购 |
| B站及其他视频 | 操作、横评、实验与复验 | 字幕/口述/画面分开；DOM缺评论时可用已授权原生AX/截图滚动 |
| 京东 | SKU、卖家履约、报价及到货 | 自营标记、混款评价、账号券/补贴及实际地址 |
| 淘宝/天猫 | 规格、商家、预售及履约 | 完整SKU、定金尾款、店铺身份及送装报价 |
| 拼多多 | 拼单、补贴及账号优惠 | 成团、新老客、默认规格、发货和服务范围 |
| Amazon | 特定站点卖家、当地/跨境购买 | 市场、卖家/履约方、地区版本、币种税运、保修及退运 |
| Temu | 特定市场和账号报价 | 目标国家可配送、实选规格、活动资格、税运及退换 |
| 识货/慢慢买/什么值得买及当地比价站 | 渠道、促销和历史 | 实际卖家、资格、同款件数及历史窗口；不当全网覆盖 |
| 其他当地论坛/零售评论 | 地区版本、本地使用 | 是否真用过、准确版本、日期、商业关系及共同来源 |

国际平台先固定站点、收货市场和进口方向；Amazon的Sold by与Ships from分别记录。地区URL、页面语言或货币不能单独证明条款市场，正文与账号地区冲突时留缺口。按需参照[公开市场资料](expansion-notes.md)；公开帮助页可读不等于账号选款、报价或配送已打通。

## 工具与路线

按用户指定方式和当前已授权可用能力选择浏览器连接、原生电脑控制、已验证手机或明确授权API。先读工具文档，观察结果再操作，不因名称含shopping就视为覆盖全部阶段。

商品/联盟API只支持实际返回且已核字段，不自动提供小红书原帖评论、账号券、车内确认价、当前地址到货或执行权。API确实支持账号动作时，仍按字段、账号、地区及授权分别验。不要读Cookie或调用非公开接口补缺口。

DOM、原生AX、截图和手机可互补，分别保留范围。普通加载、登录或输入故障可按工具规则检查页面、登录和遮罩，有根据地重试或切换已授权入口。工具、站点或权限安全拒绝则必须停止被拒绝动作及等效绕行，不能换浏览器、原生控制、手机或接口复现；用户解锁或登录不自动解除拒绝，只继续规则明确允许的其他独立工作。原生操作仍可能遇验证；需用户认证就交接，不宣称后端保证避开人机验证。

## 合并证据

先匹配 `product_identity`，再分别保留 `offer`。体验 `claim`可跨入口引用，但版本和条件须吻合。同型号不同成色、数量、套装、卖家、币种、地址或优惠，不能压为一条最低价。

同一报告/实验被作者、视频、评论和聚合重复引用，保留同一来源组。新增实物观察、独立实验及成交条件另计，渠道数不等于独立证据数。未覆盖留未核，最终只称“已核渠道中”的价格、到货及执行状态。
