# ShoppingLikeLocal 离线评测材料

八案固定输入用于不同技能版本对比。全部资料均为人工模拟，品牌、型号、商家、报告与价格不代表真实市场；没有为模拟来源编造网址。

## 输入与运行

1. 每个“版本 × 案例”使用全新上下文，只注入相应版本技能及同一案例。
2. 传入 cases.json 的 data_notice、default_environment，以及该案 user_request 和 materials；不传其他案例。
3. 这是离线资料判断任务，网络、真实账号和UI操作不可用。
4. 两版本使用相同模型、推理设置、输出预算及运行条件，可打乱顺序并记录随机种子。
5. 保存完整回答、版本或提交哈希、输入哈希、模型设置、顺序及时间。
6. 评分由独立控制器在回答后完成，评分材料不随解题输入发送；独立评分者在作答后读取单独的 rubric.json。

## 本次实际执行

最终发布候选已按每案独立新上下文重跑八案，得分800/800，见 [release-v2报告](results/release-v2/summary.md)。保留此前[final-v2快照](results/final-v2/summary.md)、[三个定向案例](results/followup-2026-10-23/summary.md)及[24工作包中的中间797分](results/parallel24/summary.md)，各自绑定不同输入快照，不混计。各轮答案、哈希、观察时间和限制均可查。[旧版保存答案](results/v1-baseline.md)只覆盖c07/c08，不是八案完整基线，也未补造历史运行设置。

[评分规则](rubric.json)为生成答案前冻结的设计文件，其status字段记录设计时状态；实际执行状态以结果报告为准。解题代理不接收评分规则。100分表示满足这套有限评分项，不代表现实准确率100%。本次配对两案没有观察到分数提升。

操作平台的真实验证另见 [平台记录](../examples/platform-validation-2026-10-22.md)，不能用离线答案代替手机或结算成功。
